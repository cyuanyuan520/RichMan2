# 游戏规则（v1，已实现引擎规则）

## 基本流程

2–4 名玩家从起点出发，轮流掷两枚骰子前进；落在无主地产可选择购买，
落在他人地产需支付过路费；经过起点领取薪水。目标是让对手破产，
或在限定回合数结束时拥有最高净资产。

回合状态机：`await-roll`（掷骰 / 用道具 / 用技能 / 缴纳保释）→ 移动与
逐格结算 → `await-decision`（购买、选择目标、遥控骰子、筹集欠款）→
`action-window`（升级、变卖、抵押、赎回、买道具、买彩票、结束回合）。
双数可再掷一次；连续三次双数直接入狱。

## 经济与地产

- 初始资金 20000；经过起点 +2000；停留起点额外 +1000。
- 地产 8 组 22 块，价格 600–2600；每块可升级 4 级，租金随等级递增
  （基准租金的 1 / 2.5 / 5 / 8 / 12 倍，取整到十位）。
- 集齐同组全部地产：该组租金 ×1.5。
- 交通枢纽 4 处（1500），按持有数量收租 250 / 500 / 1000 / 2000。
- 公共事业 2 处（1200），过路费 = 骰子点数 × 4（持 1 处）或 × 10（持 2 处）。
- 抵押：按地价 50% 获得现金，赎回需支付 10% 利息；抵押期间不收租。
- 变卖建筑：返还升级投入的 50%；必须先拆完建筑才能抵押。
- 欠款（现金为负）时进入「筹集欠款」决策：变卖 / 抵押直到现金 ≥ 0 自动
  结清；若全部资产变卖后仍不足，则自动破产，也可主动宣布破产。
- 破产：资产回到银行，现金转给债主（若有），道具清空。

## 特殊格子

- 机遇 / 命运：抽卡并按效果结算（红包、罚款、维修、住院、入狱、横财、
  均富、获得道具、传送到起点等）。卡牌效果由数据层声明式定义。
- 监狱：暂停行动，可缴纳 1500 保释；或掷出双数越狱（并照常前进）；
  持有「出狱许可」自动使用。
- 医院：住院 2 回合（名医被动减 1）。
- 税务局：所得税 = 现金 10%；奢侈税 = 1500；锦鲤的被动可减半负面金额。
- 道具店：购买道具（路障限前方 6 格内放置）。
- 彩票行：1000 元一张，每回合限购一张；奖金 0 / 0 / 2500 / 15000。
- 连续三次掷出双数：直接入狱。
- 路障：对手经过时被迫停下并移除，停下的格子照常结算。

## 道具（10 种）

遥控骰子（指定下一次点数）、路障、免租卡、拆迁卡（降 1 级建筑）、
停留卡（对手暂停 1 回合）、均富卡（现金平均）、购地卡（1.5 倍价强制收购）、
查税卡（对手 10% 现金）、传送卡（移动到任意格）、换位卡（与对手换位）。
目标型道具使用后进入目标选择决策，可取消且不消耗。

## 角色（6 名）

财神爷（过起点额外 +1000）、学霸（买地/升级 -15%）、名医（住院 -1；
主动：出狱一次）、锦鲤（负面金额减半）、熊孩子（主动：每人付 300，
冷却 3 回合）、貔貅（收租 +15%）。主动技能支持充能次数与回合冷却。

## 模式与胜负

- 单机人机：1 名真人 + 1–3 名 AI（简单/普通/困难）。
- 在线联机：创建/加入房间（PeerJS），支持 AI 补位、断线重连、快捷聊天。
- 胜负：最后存活者获胜；若设置回合上限，则回合结束时净资产最高者获胜。
- 净资产 = 现金 + 地产（抵押中的按地价 50% 计）+ 建筑投入。
