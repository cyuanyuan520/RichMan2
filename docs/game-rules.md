# 游戏规则（v1 草案，实现进度随阶段更新）

## 基本流程

2–4 名玩家从起点出发，轮流掷两枚骰子前进；落在无主地产可选择购买，
落在他人地产需支付过路费；经过起点领取薪水。目标是让对手破产，
或在限定回合数结束时拥有最高净资产。

## 经济与地产

- 初始资金 20000；经过起点 +2000；停留起点额外 +1000。
- 地产 8 组 22 块，价格 600–2600；每块可升级 4 级，租金随等级递增
  （基准租金的 1 / 2.5 / 5 / 8 / 12 倍，取整到十位）。
- 集齐同组全部地产：该组租金 ×1.5。
- 交通枢纽 4 处（1500），按持有数量收租 250 / 500 / 1000 / 2000。
- 公共事业 2 处（1200），过路费 = 骰子点数 × 4（持 1 处）或 × 10（持 2 处）。
- 抵押：按投入 50% 获得现金，赎回需支付 10% 利息；抵押期间不收租。
- 破产：现金为负且无力变卖时出局，其地产回归银行。

## 特殊格子

- 机遇 / 命运：抽卡结算（红包、罚款、维修、住院、入狱、横财等）。
- 监狱：暂停行动，可缴纳 1500 保释；或掷出双数越狱（并照常前进）。
- 医院：住院 2 回合（名医被动减 1）。
- 税务局：所得税 = 现金 10%；奢侈税 = 1500。
- 道具店：购买道具卡；彩票行：500 买彩票，奖金 1500 / 6000 / 30000。
- 连续三次掷出双数：直接入狱。

## 道具（10 种，节选）

遥控骰子、路障、免租卡、拆迁卡、停留卡、均富卡、购地卡、查税卡、传送卡、换位卡。

## 角色（6 名，节选）

财神爷（过起点额外收入）、学霸（买地/升级 -15%）、名医（住院 -1，主动出狱一次）、
锦鲤（负面金额减半）、熊孩子（主动向每人收 300，冷却 3 回合）、貔貅（收租 +15%）。

## 模式与胜负

- 单机人机：1 名真人 + 1–3 名 AI（简单/普通/困难）。
- 在线联机：创建/加入房间（PeerJS），支持 AI 补位、断线重连、快捷聊天。
- 胜负：最后存活者获胜；若设置回合上限，则回合结束时净资产最高者获胜。
